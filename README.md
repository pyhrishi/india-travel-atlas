# India Travel Atlas

The best places in every Indian state and union territory (3,900+ places, 235 trails), on one interactive map. Built with Claude.

**Install on iPhone:** open the site in Safari, tap Share, then **Add to Home Screen**. It opens full-screen and works offline.

- Map: d3 + topojson, state outlines, district lines (INDIAN-SHAPEFILES), rivers and ranges (Natural Earth)
- Data: `data/index.json` (all places), `data/places/<state>.json` (full descriptions), `data/districts/`
- Your visits, saves and trips are stored on your device only.
